# Givy

Interactive gift store demo (React + Vite + Motion). Pendants, hair clutchers, scrunchies, earrings and hampers, with a 3D gift box, gift finder quiz, customizer, cart, saved addresses and demo auth.

Demo only: no backend, no payments. Accounts, orders and messages live in the browser (localStorage).

## Run
    npm install
    npm run dev

## Google login
Paste your OAuth client ID in `src/config.js` (or set `VITE_GOOGLE_CLIENT_ID`). Add your site origin under Authorized JavaScript origins.
